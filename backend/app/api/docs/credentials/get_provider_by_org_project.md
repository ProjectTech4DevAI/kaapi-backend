Get credentials for a specific provider within an organization and project.

Retrieves decrypted credentials for a specific provider (e.g., `openai`, `langfuse`) for the specified organization and project. Requires superuser access.

### Path Parameters:
- **org_id**: Organization ID
- **project_id**: Project ID
- **provider**: Provider name (e.g., `openai`, `langfuse`, `google`, `sarvamai`, `elevenlabs`)
