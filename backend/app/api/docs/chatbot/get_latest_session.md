Get the most recently created chatbot session for the given `contact_ref` and `chatbot_ref` in the caller's project.

Both refs are required and matched exactly. `chatbot_ref` is the value returned when the chatbot's first session was created (or the one sent on later creates). The response carries the session's current `status` (`active`, or `inactive` once a newer session for the same contact and chatbot was created), its `completion_status` (`in_progress` until every field the system prompt asks for is collected, then `complete`; `abandoned` if it was superseded while still `in_progress`), and the flat `collected_fields` map (`{field_name: value}`) gathered so far. Returns 404 when the contact has no sessions for this chatbot in this project.
